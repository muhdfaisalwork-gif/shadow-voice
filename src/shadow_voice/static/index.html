    Eyebeam & X-Lite VICIdial Connection Guide
    
                        
    How softphones bridge calls between VICIdial agent screen and Shadow Voice
    
                    
    
                
    
                
            
    

            
    
                
                
    
                    
    How VICIdial Agent Login Works With Softphones
    
                    
    In VICIdial, every agent uses Eyebeam or X-Lite to log into the campaign. When you log into the web agent screen (agc/vicidial.php), VICIdial calls your softphone. The softphone auto-answers, placing you into the MeetMe conference room (e.g. 8600051). When the predictive dialer connects with a customer, it dumps the customer into that conference!
    
                
    

                
                
    
                    
    
                        
    Step 1: Check Extension in VICIdial Admin
    
                        
    In VICIdial Admin → Admin → Phones → Add/Edit phone: Extension 1001, Protocol SIP, Login 1001, Password test1001, Status ACTIVE.
    
                    
    

                    
    
                        
    Step 2: 1-Click Auto-Provisioning for Eyebeam (.reg)
    
                        
    Click "Download .reg" or "Apply to Registry" in Shadow Voice Studio. This automatically configures Eyebeam's SIP account with your extension, VICIdial IP, and turns on 0-ring Auto-Answer!
    
                    
    

                    
    
                        
    Step 3: Enable Auto-Answer in Eyebeam
    
                        
    If configuring manually: In Eyebeam, right-click → Options → Calls → Check "Auto Answer after 0 rings". This ensures calls from VICIdial are picked up instantaneously.
    
                    
    

                    
    
                        
    Step 4: Log Into VICIdial Web Agent Screen
    
                        
    Open http://<VICIDIAL_IP>/agc/vicidial.php → Phone Login: 1001, Phone Pass: test1001, User: 6666, Campaign: your campaign → Eyebeam will auto-answer and you'll hear "You are the only person in this conference".
    
                    
    

                    
    
                        
    Step 5: Or Use Headless Virtual SIP Softphone
    
                        
    Want zero desktop windows open? Use the built-in Virtual SIP Agent! Click "Connect to VICIdial" in the studio. Shadow Voice registers directly to Asterisk over SIP and auto-answers MeetMe calls straight into the AI voice engine.
    
                    
    
                
    
            
    

            
    
                Need Eyebeam running? Click "Launch Eyebeam" on the workstation card.
