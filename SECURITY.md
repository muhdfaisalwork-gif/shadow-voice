# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 2.x.x   | :white_check_mark: |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability
If you discover a security vulnerability within Shadow Voice, please open a private security advisory on GitHub or contact the maintainers directly. Please do not open a public issue for sensitive security findings.
