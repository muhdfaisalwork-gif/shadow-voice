# Contributing to Shadow Voice

We love your input! We want to make contributing to Shadow Voice as easy and transparent as possible, whether it's:
- Reporting a bug in the telephony gateway, softphone hub, or cognitive brain
- Discussing the current state of the code
- Submitting a fix
- Proposing new dialer adapters or LLM/TTS providers

## Pull Requests
1. Fork the repository and create your branch from `master`.
2. Clone the repository locally.
3. Install in editable mode: `pip install -e .`
4. Run the full test suite: `pytest -v`
5. Ensure all 149+ unit and integration tests pass.
6. Submit a pull request!
